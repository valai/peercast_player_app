# 確定した実装計画

環境構築後も以下をアプリ本体の要件として維持する。

- FlutterでiOS / Android共通のネイティブアプリ。個人・少人数向け。
- 初回起動で既定のYPを有効なYPとして登録。index.txtの公式取得先を実装時に確認する。
- YP追加・編集・削除を保存。全削除も保持し、初期値を再挿入しない。
- 複数YPを独立して取得し、一方の障害で他方を消さない。検索・お気に入り・履歴。
- PeerCast YT C++コアをFFIで端末内に組み込み、FLV（H.264/AAC）を再生。Androidはvideo_player（Media3）、iOSはmedia_kit。Androidの描画互換性による変更理由はNATIVE_CORE.mdを参照。
- 前景視聴中のみリレー。背景移行で再生と通信を終了。初期値はWi-Fiのみ、下流最大1。
- 待受ポート・リレー数を設定可能にし、実際の下流接続数と送信量を表示。
- 待受の成功と外部からの到達性を区別する。独自サーバーは運用しない。
- YPコンタクトURLから対応掲示板を判別。WebViewで閲覧・標準フォーム投稿。
- 板URLならスレッド選択、スレッドURLなら直接表示。選択をチャンネルごとに保存。
- 動画と掲示板を縦画面では上下、横画面では左右に配置。入力時も動画を維持。
- 内部境界はChannelDirectory、PeerCastEngine、PlaybackController、BoardResolver。
- コアのライセンス・配布条件を確認。モバイルへの移植可否を先に検証。
- 直接方式が成立しない場合のみ外部の視聴変換サービスの埋め込みを検証。API・埋め込み可否は未確認。
- Android/iPhoneで30分視聴と別PeerCast端末への実中継を検証。
- 投稿試験は管理下のテスト掲示板だけで行う。
- WMV、配信開始、録画、背景再生、ストア公開は初版対象外。
