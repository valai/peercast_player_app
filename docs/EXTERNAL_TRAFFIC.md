# 外部送信表示

視聴画面の「外部送信」は、外部へのソケット書き込み成功バイト数の差分を、
実際の経過時間（単調増加時計）で割った送信速度を Mbps で表示する。
1 Mbps = 1,000,000 bit/s。1秒以上の間隔で更新し、測定開始直後は0とする。
複数のリレーがある場合は合計。映像・音声以外のPeerCast制御通信も含む。
コアの `host.localIP()` 判定に従い、ローカル再生やLAN内宛ての通信は除外する。
OS・回線全体の通信量やTCP/IPヘッダー、TCP再送分を測るものではない。

以前の「外部送信 5.3 MB」は速度ではなく、エンジン開始後の累計を
1,048,576で割った値だった（正確な単位はMiB）。1 Mbpsで約44秒分に相当し、
この表示だけから過剰送信とは判断できない。画面の配信時間はリレー継続時間ではない。

以前は32ビットの全送信量とローカル送信量を別々に取得して減算していたため、
累計の周回や更新タイミングのずれで不正確になる可能性があった。
現在はTCP/TLS双方の送信成功時に、外部送信のみ64ビットatomicカウンターへ加算する。
累計 `bytesOut` は内部の診断値として維持し、表示には `outboundMbps` を使用する。
カウンターと速度はエンジン開始時にリセットする。

回帰テストは `PEERCAST_EXTERNAL_TRAFFIC_TEST=ON` でビルドする
`external_traffic_test`。ローカル除外、4 GiB超、同時送信、1 Mbps換算、
測定間隔の変動、送信停止、再開始を検証する。
